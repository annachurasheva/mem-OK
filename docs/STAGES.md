## mem (расширение) — ПРИОРИТЕТ, ускорение
- Назначение: координатор контактов с потомками в ОК: общий реестр
  контактов; охлаждение «повтор не ранее 2 недель»; чтобы Иванову И.И.
  не терзали (76 лет, три недели слёз — не повторять).
- Роли ОК: суперадмин (API, реклама/донат), админ, модератор (личка),
  редактор (новости/карточки, без лички). Лички — канал; со страницы = бан.
- Шаблоны нумерованные с основанием (адрес ЦАМО → 3; фамилия → 7).
- Хабы = ОК-страницы: сельские библиотеки, храмы (сударыни, знают всё
  население локации).
- OK API → перс. карточки бойцов сообщества.
- Трек А точка №1: плита = кровный родственник (Корпечь).
- Кадет-трек реален (зять, пятиклашки, впервые).
- CSV: mem/data/raw (парсер ЦАМО, неизменяемо) + data/parsed.
- Горизонт: 20+ недель.
