## Как передавать записки памяти

```
1. Записка живёт в репо: docs/ZAPISKA.md — короткая,
   человеческими словами (это парковка, не этажи).
2. Первое сообщение нового диалога = координаты, не контент:
   «репо alex-6675/mem-OK; прочитай docs/ZAPISKA.md и работай
   по её правилам; один ток — один шаг».
3. Клон без записки = клон на площадке без присмотра: не
   доверяем (спиной не поворачиваемся) и в этажи не ходим:
   диалог вырос → обновили записку одной строкой → закрыли →
   новый с запиской.
```

## Скелет записки (короткий)

```
# Записка памяти · vN · дата
Владелец: уровень начальный; человеческие слова; эвфемизмы;
термины — Кодеру.
Правила: один ток — один шаг — один отчёт; file-first;
provenance (координата·время·автор); 3 метра — предел кодера,
TASK мелкий; эталон джуна (что·зачем·если убрать); LLM не
красит и не фантазирует.
Словарь: слон = ЗАЧЕМ; шатёр = стойкая маркировка; цирк =
ансамбль; дверь/ключ; парковка = текущий диалог; площадка =
новый диалог клона (входить только с запиской); этажи =
глубокий контекст (не ходить, спиной не поворачиваться).
Сделано: слон (метка+дверь+ранги), маркировка ОК, экспорт/импорт.
Дальше: тест персистентности метки и двери → надув → окраска.
Косяки: ноль.
```
