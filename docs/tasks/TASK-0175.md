   меню должно пересоздаваться на каждом старте service worker.
Проверка: открой EdgeExtension/src/background.js и dist/src/background.js,
покажи наличие/отсутствие строки importScripts slonbg.js.

## Директива (исполнять точно, без инициатив)
1. EdgeExtension/src/background.js: сразу после строки
   importScripts("./core/slonstore.js");
   добавить строку:
   importScripts("./slonbg.js");
2. EdgeExtension/src/slonbg.js: создавать меню идемпотентно НА КАЖДОМ старте SW:
   chrome.contextMenus.remove("slon-door", () => { void chrome.runtime.lastError;
     chrome.contextMenus.create({ id: "slon-door", title: "Слон: статус…", contexts: ["link"] }); });
   Вызывать при старте SW и в onInstalled. Id меню один: "slon-door".
3. Координату своим парсером НЕ считать. В slonbg.js (клик меню) и slonmarks.js (метки)
   вызывать ТУ ЖЕ донорскую функцию нормализации, которую вызывает content.js
   для меню «Записка» (см. лог content.js:52). Свои regex убрать.
4. НЕ блокировать на фильтре следующие координаты:
   - profile/NNN и его субстраницы (…/video, …/photos, …/friends и т.п.):
     координата = profile:NNN, субпуть новой координаты не создаёт
     (пример: https://ok.ru/profile/440340712355/video → profile:440340712355);

     (ok-_music_track_…, ok-_video_…, ok-_app_vk_app…);
   Исключаются только служебные ссылки (logout, настройки, пустой href).
