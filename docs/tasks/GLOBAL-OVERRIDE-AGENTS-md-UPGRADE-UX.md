**ТЗ НА АПГРЕЙД UX (ДВЕРЬ И АВТОЗАХВАТ)**
Проектировщик утвердил новую логику работы с дверью. Убираем лишние шаги (F5, ручной ввод).
1. **Автозахват контекста:** При клике на «Слон: статус...», `slondoor.js` сам считывает `location.href` текущей вкладки (или вкладки, откуда был вызов, если это background). Если это страница профиля/группы ok.ru — скрипт сам парсит координату и время.
2. **Автозаполнение координаты:** Окно двери открывается с подхваченной координатой и временем. Поля «Координата» и «Время» заполнены автоматически.
3. **Бинарный выбор:** Пользователь видит готовую карточку. Ему остаётся только выбрать ранг, написать `descript` (если нужно) и нажать «Сохранить» или «Сброс» (отмена без записи).
4. **Персистентность:** Если координата уже есть в базе, окно открывается в режиме редактирования (с историей). Если нет — в режиме создания.

**ТЗ ПО ЧИСТОТЕ ПОЛЕЙ (СТРОГОЕ ТРЕБОВАНИЕ)**
В секцию `descript` (Пояснение) окна двери **НЕЛЬЗЯ** вписывать никакие предустановленные тексты, мифологемы или интерпретации. 
* Поле `descript` (и любые другие текстовые поля формы) должны быть **СТРОГО ПУСТЫМИ** (`value=""` или `<textarea></textarea>`) при открытии двери для новой записи.
* Никаких `placeholder` с чужими текстами.
* Управляющий заполняет смыслы с нуля.
* Твоя задача: подогнать CSS формы так, чтобы поле `descript` было чистым, пустым и готовым к вводу текста любой длины (используй адаптивный размер шрифта или `flex-wrap` для контейнеров, чтобы ничего не ломалось при пустом или заполненном состоянии).
